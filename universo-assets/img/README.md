# Imágenes de /universo

Las imágenes de `universo.html` viven aquí. Para reemplazar una, conserva el
nombre exacto o actualiza su ruta en el HTML.

Formato: WebP, calidad ~78–82. Tono cálido: mármol marfil, dorado antiguo,
cielo nocturno azul-negro, luz cinematográfica lateral. Sin morados ni
saturación.

## Imágenes de la landing

| Archivo | Origen |
|---|---|
| `cielo-noche.webp` | `assets/fondo.png` redimensionado (fondos del hero, testimonios, valores y cierre, y base de las imágenes) |
| `libro-tapa.webp` | Recorte de la tapa de `assets/portada-carta-natal.png` (libro en "Producto" y portada del carrusel) |
| `hero-escultura.webp` | Imagen generada para el hero; también se recorta como arte decorativo en FAQ |
| `arco-luna.webp` | Imagen generada para el formulario gratuito: templo, luna y montañas |
| `arco-columnas.webp` | Imagen generada para la franja de la sección del producto |

## Testimonios

Los testimonios de `universo.html` son placeholders (`data-placeholder`).
Reemplázalos solo por testimonios reales con permiso de cada persona, y
quita el atributo `data-placeholder` para eliminar el borde punteado.
